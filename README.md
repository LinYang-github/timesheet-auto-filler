## 📖 项目简介

**智能工时填报生成器** 是一款专为解决繁琐工时报表填报而设计的效率工具。在许多企业环境中，员工需要根据每月统计的“标准月工时”反向拆分并填充到周报或日报中。本工具通过读取标准工时 Excel 数据及工作内容语料库，利用智能算法自动分配工时并生成符合格式要求的 Excel 报表。

### 核心价值
- **自动化计算**：自动将月度系数转化为标准天数。
- **灵活分配**：支持“按周填报（每周六一条记录）”或“按天填报（工作日优先填充）”两种模式。
- **随机化处理**：自动从语料库中随机匹配工作类型与内容，使报表看起来更真实、多样化。
- **零后端依赖**：完全基于纯前端实现，数据处理均在本地浏览器完成，确保信息安全。

## ✨ 功能特性

- 📂 **双文件导入**：支持上传标准工时源文件与任务语料库。
- ⚙️ **参数高度可调**：
  - 自定义月度天数系数（默认 21.75）。
  - 设置单行最大填报天数限制。
- 📅 **智能排期**：自动识别年份与月份，计算当月周六日期或工作日分布。
- 📊 **一键导出**：生成标准的 `.xlsx` 文件，包含姓名、日期、年份、月份、工时类型、工作内容及消耗天数。
- 🎨 **现代化 UI**：基于 Tailwind CSS 构建的响应式界面，交互逻辑清晰。

## 📅 数据准备要求

为确保程序正确解析，请提供以下格式的 Excel 文件：

### 1. 标准工时数据源
- **Sheet 命名**：必须以年份命名（如 `2024` 或 `2025`）。
- **列要求**：
  - 必须包含 `姓名` 列。
  - 必须包含以月份命名的列（如 `1月`, `2月` ... 或直接为数字 `1`, `2`）。
- **单元格内容**：数值型，代表该月的人月系数。

### 2. 工作内容语料库
- **Sheet 命名**：默认读取第一个 Sheet 或名为 `Sheet2` 的表格。
- **列要求**：
  - `工时类型`：如“常规工作”、“研发活动”等。
  - `工作内容`：具体的任务描述文字。

## 🚀 快速启动

### 开发环境运行
1. **安装依赖**:
   ```bash
   npm install
   ```
2. **启动开发服务器**:
   ```bash
   npm run dev
   ```

### 生产构建与本地部署
如果您需要构建项目并在本地环境（如离线内网）中运行，请按照以下步骤操作：

1. **执行构建**:
   ```bash
   npm run build
   ```
   构建完成后，所有的静态资源将生成在 `dist` 目录下。

2. **使用 Python 启动本地服务**:
   进入 `dist` 目录并启动 HTTP 服务（无需 Node.js 环境，仅需 Python）：
   ```bash
   cd dist
   python3 -m http.server 8085
   ```
   启动后，在浏览器访问：`http://localhost:8085`

## 📝 配置文件说明

项目核心逻辑位于以下服务组件中：
- `services/excelService.ts`: 负责 Excel 文件的解析与导出 Blob 流。
- `services/generatorService.ts`: 核心分配算法，包括随机权重分配函数 `distributeRandomly`。
- `types.ts`: 定义了统一的数据接口模型。
